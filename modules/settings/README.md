# Fokus settings module

Admin.php controls template appearance and workspace settings. The Fokus Butler Modules page controls pane adapters and reports external dependencies. The template owns its settings schema and appearance tokens. Open Admin → Fokus Butler → Fokus settings.

This is an internal Fokus Butler module, not a separately installable DokuWiki plugin. See [the companion README](../../README.md) for installation, module switches, asset loading, and development checks.
